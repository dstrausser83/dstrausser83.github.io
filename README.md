# dstrausser83.github.io

David Strausser's personal brand site — free, ad-free, hosted on GitHub Pages.

**Live:** https://dstrausser83.github.io/

## Structure

- `index.html` — one-page site: hero, about, work (ERP services), life, shop (coming soon), contact
- `assets/css/styles.css` — dark rock theme, responsive, no frameworks
- `assets/js/main.js` — mobile nav, scroll reveals, active nav highlighting
- `404.html` — branded not-found page

## Editing

It's plain HTML/CSS/JS on purpose — easy to iterate. Planned next: shop products, blog.

## Deploy

Any push to `main` redeploys automatically via GitHub Pages.
